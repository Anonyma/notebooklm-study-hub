# NotebookLM Study Hub - Claude Preferences

## Content Style Preferences

### Articles Should Be:
- **Standalone encyclopedic content** - NEVER reference "the podcast," "the discussion," "the speakers," etc.
- **Long-form** - 3,000-5,000+ words, comprehensive deep-dives
- **Written as original educational content** - as if writing for a magazine like The Atlantic or Aeon
- **Varied formatting** - mix of:
  - Prose paragraphs
  - Bullet point lists
  - Comparison tables where appropriate
  - Section headers that break up the content
  - Blockquotes for key concepts

### Articles Should NOT Be:
- Meta summaries ("In this episode, the hosts discussed...")
- Short overviews
- Listicles without substance
- Podcast transcription summaries

### Timeline Integration:
- Always show **actual years** alongside anchor numbers (not just "Anchor 18")
- Timeline position should give meaningful context about the era
- "What else was happening" section is valuable for context

### Visual Elements (User Loves):
- Interlaced images within articles
- Key figures/entities section
- Related lessons connections
- Timeline tab visualization
- Year labels on timeline

### UX Issues to Address:
- Right-hand panel scrolling is separate from article scrolling (annoying)
- Broken images need fixing (check Wikipedia URLs are valid)

## Content Quality Checklist

Before finalizing a lesson JSON:
1. ✓ Is it standalone (no podcast references)?
2. ✓ Is it 3,000+ words?
3. ✓ Does it have varied formatting?
4. ✓ Are image URLs valid and loading?
5. ✓ Does timeline show years, not just anchor numbers?
6. ✓ Are entities well-described with Wikipedia links?
7. ✓ Do quiz questions have good explanations?
